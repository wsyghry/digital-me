## 四、现在点不动的按钮 / 会踩的坑

- **分身没填 Key 就只能看提示**：.env 里 DEEPSEEK_API_KEY 空着时，提问会回 503，这是设计如此。
- **换网络地址就变**：手机用的是局域网 IP，电脑换了 WiFi 或热点，地址跟着变。
- **电脑关机 / 休眠就打不开**：本机阶段的硬限制，要随时可用得走 P4 上云。
- **同时只能一个进程写库**：`database is locked` 时就检查是不是开了两个服务（`.\run.ps1 -Stop` 后重开）。
- **分身说不出话**：提问用词跟记录差太远就命中不到（二元组匹配），换个说法；真没记过它直说不知道，不会编。
- **搜索是字面匹配**：搜「郁闷」搜不到「心情不好」，语义检索以后再说。
