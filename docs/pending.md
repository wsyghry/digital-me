## 四、现在点不动的按钮 / 会踩的坑

- **分身没填 Key 就只能看提示**：`DEEPSEEK_API_KEY` 空着时提问回 503，这是设计如此。
- **换网络地址就变**：手机用的是局域网 IP，电脑换 WiFi 或热点，地址跟着变。
- **电脑关机 / 休眠就打不开**：本机阶段的硬限制，要随时可用得走 P4 上云。
- **同时只能一个进程写库**：`database is locked` 时检查是不是开了两个服务（`-Stop` 后重开）。
- **分身说不出话**：提问用词跟记录差太远就命中不到（二元组匹配），换个说法；真没记过它直说不知道。
- **搜索是字面匹配**：搜「郁闷」搜不到「心情不好」，语义检索以后再说。
- **合并错了人**：用 `DELETE /api/aliases/<被并的名字>` 撤销，记录本身不会被改。
- **上云后接口不带登录**：目前任何人拿到域名都能读写。上云前必须加一道口令（待做，属 P4 的一部分）。
