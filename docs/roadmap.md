## P1 · 记录与搜索（本机）

**做什么**
1. 建 `.venv`，装 fastapi / uvicorn / httpx
2. `app/db/schema.sql` + `store.py`：建表、写入、两路检索（≥3 字走 FTS5 MATCH，1~2 字走 LIKE 兜底），用户输入一律转短语并转义，带标点也不报错
3. `app/api/routes.py`：`POST /api/messages`、`GET /api/search`、`GET /api/stats`
4. `web/`：记录页 + 搜索页，手机可访问
5. `run.ps1`：一键启动

**验收**
- 手机连同一 WiFi，打开电脑 IP:8000
- 记一句话，刷新后仍在
- 切到搜索页，输入记录里的三个字能搜到
- 再输两个字（比如「明天」）也能搜到，不返回空
- 输带标点的词（比如「报销（7月）」）页面正常返回，不报错
- 关掉服务重启，数据还在

**不做**：分身、导入、部署

## P2 · 分身对话与拟稿

**做什么**
1. `app/services/llm.py`：DeepSeek 调用，超时与错误提示明确
2. `persona.py` + `prompts/persona.md`：人格设定与语气样本
3. `chat.py`：检索 → 拼上下文 → 回答，返回引用来源
4. `draft.py`：输入「对方说了什么 + 我想表达什么」，出 2 条候选回复
5. 前端加「分身」页签

**验收**
- 问「我昨天记的那件事」，回答引用的是真实记录
- 问记录里没有的东西，它会说不知道，**不编**
- 拟稿页输入一段别人发来的话，出来 2 条像你会说的话
- 单次问答花费 < 0.01 元

**需要**：一个 DeepSeek API Key

## P3 · 微信 / QQ 历史导入　⚠️ 有风险，单独决策

**做什么**
1. `ingest.py`：jsonl 统一入口 + 字段校验去重
2. `scripts/import_jsonl.py`：命令行批量导入
3. 微信：PC 端本地库解密 → 清洗（去系统消息、合并多设备、人物消歧）
4. QQ：另一套解析，同样清洗
5. `data/raw/` 放原始导出，不进 git

**验收**
- 搜「三年前那个地址」能命中
- 同一个人在不同群的不同昵称能被归并
- 导入后库体积、条数、时间跨度可查

**前置判断**：这一步要碰加密数据库解密。若账号风险不可接受，可以只做「手工导出为可读文本再导入」，功能略损但零风险。

## P4 · 上云

**做什么**
1. 买轻量服务器（香港 2C2G，免备案）
2. 域名解析 A 记录指向服务器，Caddy 自动签 HTTPS
3. 服务常驻（systemd 或 Windows 服务），开机自启
4. 每日自动备份 `me.db`

**验收**
- 关掉家里电脑，手机流量下仍能记录和搜索
- HTTPS 证书有效，手机不报不安全
- 随机删一条，能从备份恢复

**需要**：域名 DNS 管理权限；若选大陆地域则需 ICP 备案
